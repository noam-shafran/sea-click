# sea-click

משחק לחיצות מרגיע עם שקיעת ים 🌅

## איך לשחק

**[לחץ כאן כדי לפתוח את המשחק](https://noam-shafran.github.io/sea-click/)**

### במחשב
- לחץ על הלינק למעלה
- בחר או צור שם שחקן
- לחץ על הכפתור האדום (או מקש הרווח) להתחלה
- לחץ הכי הרבה שאתה יכול תוך 5 שניות!

### בטלפון
1. פתח את הלינק בדפדפן (Chrome / Safari)
2. לשמירה במסך הבית:
   - **Android (Chrome):** תפריט (⋮) → "הוסף למסך הבית"
   - **iPhone (Safari):** לחץ על כפתור השיתוף → "הוסף למסך הבית"
3. עכשיו אפשר לפתוח את המשחק מאייקון במסך הבית
