# מוזיקת רקע

כדי להוסיף מוזיקת רקע מרגיעה במסך הפתיחה:

1. הורד קובץ MP3 מרגיע (פסנתר, אמביאנט וכו') מאתר חינמי, למשל:
   - [Orange Free Sounds - Calm Piano](https://orangefreesounds.com/calm-relaxing-piano-music/)
   - [Pixabay - Relax](https://pixabay.com/music/search/relax/)
   - [Mixkit - Ambient](https://mixkit.co/free-stock-music/ambient/)

2. שמור את הקובץ בשם `background.mp3` בתיקייה זו

אם אין קובץ מקומי, המשחק ינסה להשתמש במקור רשת (אם מותר בדפדפן).
