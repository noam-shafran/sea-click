# מוזיקת רקע

כדי להוסיף מוזיקת רקע מרגיעה (רעש ים) במסך הפתיחה:

1. הורד קובץ MP3 של רעש ים מרגיע מאתר חינמי, למשל:
   - [Pixabay - Ocean Sounds](https://pixabay.com/sound-effects/search/ocean/)
   - [Mixkit - Ocean](https://mixkit.co/free-sound-effects/ocean/)
   - [Orange Free Sounds - Ocean Waves](https://orangefreesounds.com/ocean-waves/)

2. שמור את הקובץ בשם `ocean.mp3` בתיקייה זו

אם אין קובץ מקומי, המשחק ינסה להשתמש במקור רשת (אם מותר בדפדפן).
